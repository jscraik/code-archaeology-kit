# Security Policy

## When to use
Use this document to report a security vulnerability.

## Inputs
- A clear description of the issue and impact
- Minimal reproduction steps (if possible)

## Outputs
- A coordinated fix and disclosure process

## Reporting a vulnerability

Please use GitHub Security Advisories for private reporting (preferred). If private reporting is not available for this repository, contact the maintainer via GitHub (@jscraik).

## Supported versions

This project is early-stage. Security fixes will be released as needed; please prefer upgrading to the latest release.
