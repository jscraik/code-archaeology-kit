# Instruction map

## Scope

Use this guide when changing files in this repository.

## What to read first

- `README.md`
- `CONTRIBUTING.md`
- `pyproject.toml`
- `package.json`
- Root `AGENTS.md`

## Mandatory task flow

1. Verify request scope.
2. Read only the relevant instruction document.
3. Apply minimal, verifiable changes.
4. Run checks in `docs/agents/04-validation.md`.

## Additional flow for frontend or GitHub Pages work

- Read `docs/agents/06-frontend-website-rules.md` before editing UI-facing files.

## When not to use

- Do not treat `docs/competition-matrix.md` as execution policy.
